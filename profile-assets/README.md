# profile-assets

Images used by the profile README, hosted here so they don't depend on third-party repos.

- `animated-line.svg`: the animated divider line. Copied unmodified from
  [readme-SVG/animated-line](https://github.com/readme-SVG/animated-line)
  (`STORAGE/line-svg-000000.svg`, created by OstinUA and the readme-SVG org), licensed under
  Apache-2.0. See `LICENSE-animated-line.txt`.
- `substack-*.svg`: rounded thumbnails for the latest Substack articles. Generated and pruned
  by `.github/scripts/update_substack.py` on each workflow run. Don't edit by hand.
